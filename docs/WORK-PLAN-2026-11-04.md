# Catalogue work plan, 4 November 2026

The owner's direction: theme variants that are PWA compatible; work the layouts
repository for it; subagents build, the supervisor reviews; themes are tested,
on edge where a host is needed; deliver every open inbox item; where a layout
or theme depends on an engine version, state it in the files and file a check
to the engine.

Branch: `claude/catalogue-2026-11` (integration). Each agent works on its own
branch off `main` in its own worktree and is merged here after review. Nothing
is pushed. Commits end with `Assisted-by: Claude:<model>`.
